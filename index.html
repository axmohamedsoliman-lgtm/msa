Windows SmartScreen Installation Guide

This is normal for new applications!

Windows SmartScreen shows this warning for all new applications that haven't been downloaded many times yet. Our application is 100% safe and contains no malware.

How to Install Safely:

  1. Click "More info" on the Windows SmartScreen warning
  2. Click "Run anyway" to proceed with installation
  3. The installer will verify itself - this takes about 10 seconds
  4. Follow the standard installation wizard (next, next, finish)
  5. Launch Modern Server Administrator from your Start Menu

Why this happens:

We're a new application without thousands of downloads yet. Windows SmartScreen protects users by warning about unfamiliar software. Once enough users install it, this warning will disappear automatically.
