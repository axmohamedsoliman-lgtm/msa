What It Does

Current features and what's coming next

Zero Configuration Available Now

Drop your project folders and start coding immediately. Auto-detects PHP, Node.js, Flask, and static sites with intelligent project analysis. Just works.

Web Dashboard Available Now

Clean web interface for managing your local projects. Real-time logs, server status, and basic monitoring. No complexity.

Local Security Available Now

All data stays on your machine. No cloud dependencies. Works offline and respects your privacy.

Public URL Sharing In Beta Testing

Create secure tunnels to share your local servers. Useful for testing on mobile devices or showing work to clients.

Hot Reload In Beta Testing

Automatic server restarts when files change. Saves time during development. Currently being refined.

Extensibility Planned

Plugin system for custom extensions. We're building this based on community feedback and needs.
